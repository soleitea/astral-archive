ASTRAL ARCHIVE — Honkai: Star Rail fan archive
نسخة أولية قابلة للتشغيل على GitHub Pages.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html للمعاينة محلياً.
3) ارفع الملفات الأربعة (index.html, style.css, data.js, app.js) إلى جذر مستودع GitHub.
4) من Settings > Pages اختر Deploy from a branch ثم main / root.

ملاحظات:
- شاشة القطار مرسومة داخل الموقع بصيغة SVG أصلية مستوحاة من أجواء قطار فضائي، وليست صورة رسمية من اللعبة.
- بيانات الشخصيات والـ Light Cones والقصة في data.js. النسخة الحالية Prototype بعينة محتوى، وليست موسوعة مكتملة أو قاعدة بيانات رسمية.
- يمكن إضافة روابط الصور الرسمية للشخصيات في الخاصية img داخل data.js.
- بعض الخطوط وخلفية الصفحة الرئيسية تحتاج اتصال إنترنت.
- المشروع غير رسمي وغير تابع لـ HoYoverse.
