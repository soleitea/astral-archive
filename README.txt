ASTRAL ARCHIVE — Naya
نسخة تجريبية محسّنة لموقع موسوعة Honkai: Star Rail باللغة العربية.

طريقة الرفع:
1) فكّي ضغط الملف.
2) ارفعي index.html و style.css و data.js و app.js و README.txt إلى جذر مستودع GitHub.
3) من Settings > Pages اختاري Deploy from a branch ثم main و /(root).
4) انتظري نشر GitHub Pages ثم افتحي رابط الموقع.

ملاحظات مهمة:
- الموقع مشروع جماهيري غير رسمي ولا يتبع HoYoverse.
- الصور مرتبطة بمستودع StarRailRes المفتوح المصدر؛ إذا تغيّر مسار أي صورة ستظهر علامة بديلة تلقائياً.
- البيانات الحالية عيّنة واجهة وليست موسوعة كاملة. يجب استكمال بقية الشخصيات والمخاريط والآثار والقصص ومراجعة تفاصيل المهارات والأرقام.
- بعض صور المخاريط والشخصيات قد لا تعمل إذا تغيّر مسار ملف المصدر. استخدمي مجلدات icon في StarRailRes لتحديث المسارات.
- احترمي تراخيص المصادر الخارجية واحتفظي بإشعاراتها عند توزيع الموارد.
- حقوق تصميم الموقع: Created & Developed by Naya.
- بيانات اللعبة ورسوماتها وشخصياتها مملوكة لأصحاب الحقوق.
